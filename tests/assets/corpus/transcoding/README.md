# Synthetic JPEG transcoding corpus

Generated by `tests/assets/generate-transcoding.py` using Pillow 10.2+ and the pinned libjxl 0.12.0 tools.
All source pixels and marker payloads are generated; no external photographs or corpora are included.

Each case contains an original `.jpg`, `cjxl -e 7 --lossless_jpeg=1` output `.jxl`, and `djxl`'s 8-bit `.png`
rendering. The generator verifies `djxl` reconstructs every original JPEG byte exactly.

Twenty cases cover sequential/progressive gray and YCbCr 4:4:4/4:2:2/4:2:0, refinement, restart intervals,
optimized Huffman tables, small/odd/MCU-boundary dimensions, multiple AC and LF groups, canonical two-part ICC,
EXIF orientation, XMP, unknown/repeated APP, COM, marker fill bytes and EOI tail. Three hand-built cases add
redundant ZRL, explicit progressive reset points, zero padding, an empty DHT, and 16-bit quantization entries.

The profile timestamp is fixed. Generator commands and tools are required only for regeneration; ordinary tests
use the checked-in oracle files. Live `Category=Oracle` additionally checks newly produced JXL with `djxl`.
